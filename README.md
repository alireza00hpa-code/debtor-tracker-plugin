Debtor Tracker (Financial Operations Plugin)

This repository serves as a public overview of a proprietary, highly complex WordPress plugin built for financial operations and debt collection.

Core Features:

· Jalali (Shamsi) to Gregorian date conversion algorithms.
· Automated SMS integrations (Kavenegar, Melipayamak).
· Live-updating REST API.
· Role-based access control and legal complaint workflows.

Note: The actual production codebase is kept private due to security and privacy standards, as it handles sensitive financial and customer data. This public repository is created to fulfill the application requirements for the Claude for Open Source program.
